ℹ️ Informations

Démarrer: Lance le broker MQTT Mosquitto. Nécessaire pour que les ESP32 puissent communiquer.

Arrêter: Stoppe le broker. Toutes les connexions actives seront fermées.

Redémarrer: Arrête puis redémarre le broker. Utile après modification de la configuration.

Recharger Config: Recharge la configuration sans interrompre les connexions existantes.
